# Сайт Tabula

Сайт проєкту [Tabula](https://github.com/tabula-cms/tabula): документація для шкіл і розробників,
зібрана з теки `docs/` репозиторію Tabula, і каталог шкіл, які користуються системою.

Стан: репозиторій щойно створений, вибір генератора й домен ще не визначені.
Деталі — в issue цього репозиторію.
