import { offer } from '../../config/offer.mjs';

## Як нам написати

Напишіть на <a href={`mailto:${offer.supportEmail}`}>{offer.supportEmail}</a>.

{offer.contactPhone && <p>Телефон: <a href={`tel:${offer.contactPhone}`}>{offer.contactPhone}</a>.</p>}

Зазвичай відповідаємо протягом {offer.supportReplyDays} робочих днів.

## Що надіслати

- назву закладу й адресу сайту;
- що ви робили і що побачили;
- знімок екрана без персональних даних.
